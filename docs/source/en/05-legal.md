## 5.2. Third-Party Components

PlayForm builds upon and includes the following major third-party libraries and frameworks. Each is used under its respective open-source license.

| Component | Usage | Website |
|---|---|---|
| **mpv** | Media playback engine — audio/video decoding, rendering, and streaming for all supported formats | [mpv.io](https://mpv.io) |
| **Qt / PySide6** | Cross-platform graphical user interface framework | [qt.io](https://www.qt.io) |
| **FFmpeg** | Audio/video transcoding, extraction, thumbnail generation, audiobook binding, and format conversion | [ffmpeg.org](https://ffmpeg.org) |
| **Deno** | JavaScript runtime used internally by yt-dlp for resolving streaming URLs | [deno.land](https://deno.land) |
| **yt-dlp** | YouTube and streaming platform URL resolver for online media playback | [github.com/yt-dlp/yt-dlp](https://github.com/yt-dlp/yt-dlp) |
| **mutagen** | Audio metadata reading and writing, used alongside music-tag for the Tag Editor | [github.com/quodlibet/mutagen](https://github.com/quodlibet/mutagen) |
| **pysubs2** | Subtitle parsing, writing, and conversion library for the Subtitle Converter and Editor | [github.com/tkarabela/pysubs2](https://github.com/tkarabela/pysubs2) |
| **Qt Text-to-Speech / SAPI5** | Speech synthesis engine for the Speech Converter tool and spoken accessibility feedback | [doc.qt.io/qt-6/qttexttospeech-index.html](https://doc.qt.io/qt-6/qttexttospeech-index.html) |
| **ExifTool** | Reference implementation for PlayForm's media metadata engine; portions of its parsing approach were adapted into it | [exiftool.org](https://exiftool.org) |
